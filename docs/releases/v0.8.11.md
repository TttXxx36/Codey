# Codey v0.8.11

## 更新内容

- 版本号从 0.8.10 更新为 0.8.11，Windows 安装包使用正式版本名。
- 保留原有 Codey 功能，并继续提供 Codex 外观调整：对话区域背景图、背景显示强度、界面遮罩强度和对话内容最大宽度。
- 背景只覆盖中央对话区域，不覆盖左侧会话栏和顶部工具栏；配置会随 Codey 保存。
- 保留背景与对话宽度脚本，但不注册 Windows 开机自动启动入口；安装包只创建开始菜单快捷方式和可选桌面快捷方式。
- GitHub Actions 继续负责质量检查、Windows x64 构建和上游安全同步；本版本增加正式 Release 发布流程，安装包会直接附加到本页面。

## 验证

- Quality checks：通过
- Windows installer build：通过
- Windows x64 安装包：`Codey-0.8.11-windows-x64-setup.exe`

## 安装

下载下方的 Windows x64 安装包，运行后按向导完成安装。安装后手动打开 Codey，进入 Codex 后即可继续使用外观调整功能。
