# v0.8.13

## 性能深度诊断与修复

- 并发执行启动阶段互不依赖的路径、路由、Provider 和注入脚本准备，缩短串行等待。
- 增加默认关闭的启动耗时 JSONL trace（`CODEY_PERF_TRACE=1`）。
- 增加仅在诊断模式启用的 renderer 长任务、帧间隔和 Chromium JS 堆探针。
- 限制并立即清理虚拟化会话行的 DOM 强引用，降低长期运行内存增长风险。
- 将会话工具 DOM 观察范围限制到 `#root`。
- 完整回收 Codex 外观控制器的延迟同步定时器。
- 增加 GitHub Actions 性能审计，输出前后源码/构建指标和真实 Windows 采样说明。

## 验收边界

GitHub Actions 验证源码、构建和回归；启动至少 20% 的目标与内存泄漏归零需要同一台 Windows、同一份 Codex 数据的配对 trace 和 heap snapshot，详见 [性能报告](../performance/v0.8.13-deep-audit.md)。
