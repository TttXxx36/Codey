# Codey v0.8.12

## 更新内容

- 修复启动阶段等待网络更新检查导致的启动变慢：Codex 运行起来后再后台检查更新，不再阻塞首次交互。
- 修复点击左侧历史会话可能长时间卡住的问题：历史子会话核验改为后台执行，并为每个请求增加 1.5 秒超时保护。
- 降低外观增强脚本对页面 DOM 的扫描频率和范围，减少会话切换、流式输出时的额外开销。
- 避免在左侧会话点击的关键路径上触发大体量工具注入，降低首次切换会话时的竞争。
- 保留 Codex 自定义背景图、中央对话区域最大宽度、背景/遮罩强度和调整入口；背景仍只覆盖中央对话区域，不覆盖左侧会话栏和顶部工具栏。
- 保留背景与对话宽度脚本，但不注册 Windows 开机自动启动入口。
- 修正 Cargo.lock 中工作区运行时包的版本一致性，确保 Linux 与 Windows 的锁定构建稳定通过。
